# Metrics untuk Paper Penelitian

## 📊 Metrics Evaluasi yang Tersedia

### 1. **Traditional Classification Metrics**

Sama seperti Deep Learning, cocok untuk paper:

#### Confusion Matrix
```
                Predicted
                native ads  berita murni
Actual  
native ads      [TP]        [FN]
berita murni    [FP]        [TN]
```

#### Derived Metrics
- **Accuracy**: Overall correctness
- **Precision** (per class): TP / (TP + FP)
- **Recall** (per class): TP / (TP + FN)  
- **F1-Score** (per class): Harmonic mean of precision & recall
- **Macro Average**: Average across classes

### 2. **BERTScore** (Semantic Quality)

Mengukur kualitas reasoning/explanation:
- **Precision**: Relevansi output
- **Recall**: Kelengkapan output
- **F1**: Overall semantic similarity

### 3. **LLM-as-a-Judge** (Novel Metric)

Evaluasi oleh LLM lain (4 aspek, skala 1-5):
- **Correctness**: Ketepatan klasifikasi
- **Confidence Calibration**: Kesesuaian confidence
- **Reasoning Quality**: Kualitas penjelasan
- **Overall Quality**: Penilaian keseluruhan

### 4. **Agentic AI Specific Metrics**

- **RAG Effectiveness**: Precision@K untuk retrieval
- **Agent Latency**: Waktu per agent
- **End-to-End Latency**: Total pipeline time
- **Confidence Distribution**: Distribusi confidence scores
